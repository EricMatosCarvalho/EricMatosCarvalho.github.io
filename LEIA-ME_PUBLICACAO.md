## Instalação no GitHub Pages

1. Abra o repositório `EricMatosCarvalho/EricMatosCarvalho.github.io`.
2. Faça backup/commit do estado atual antes de atualizar.
3. Envie os arquivos mantendo rigorosamente os caminhos de diretório mostrados neste ZIP.
4. **Não remova** o arquivo original `css/main-green.css` nem as demais imagens já existentes no repositório.
5. Faça o commit e aguarde a atualização do GitHub Pages; acesse o site, atualize com Ctrl+F5 e teste as seções.
6. Se a pasta `operacao360/` não for enviada junto, o link do projeto ficará quebrado.

## Teste visual

Verifique telas de 360px, 390px, 768px, 1024px, 1440px. Os itens Início, Currículo, Competências, Portfólio e Contato devem ser navegáveis sem rolagem horizontal. Na tela pequena, o menu hamburger abre e fecha.

## Limites e honestidade

- O estudo Operação 360 usa uma empresa e dados fictícios; o código-base é material de aprendizagem, não uma realização profissional verificada do estudante.
- Revisar o período exato do serviço militar: há diferença entre currículo e LinkedIn fornecidos. A página mantém a referência resumida a 2025.
- Retrato e ícones são novas ilustrações. O formato WebP com transparência é o adequado para esta imagem estática, não é necessário GIF.
