Currículo RPG sério - Eric Matos Carvalho

Como usar no GitHub Pages:
1. Substitua o index.html do seu projeto por este index.html.
2. Substitua o css/main-green.css pelo arquivo css/main-green.css deste pacote.
3. Copie a pasta images deste pacote para o seu projeto.
4. Envie tudo para o GitHub com git add, git commit e git push.

Observação:
O visual foi ajustado para ficar mais sério e profissional, mantendo a identidade de RPG com dragão, madeira escura, bronze e vermelho.
